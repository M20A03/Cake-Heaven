## Key Features

- **Artisanal dessert catalog:** Curated menu with high-resolution imagery and fallback placeholders.
- **Custom cake configurator:** Dynamic selections for flavor, tiers, frosting, and custom lettering.
- **Firebase integration:** Cloud Firestore for menu availability and ordering.
- **Mobile ordering:** Touch-first single-page checkout optimized for fast mobile devices.

---

## Spatial Web and Mobile Viewport Specifications

- **Precision Viewport Scaling:** Responsive mobile layout with 12px gutter margins and fluid scaling.
- **Touch Ergonomics:** Standard 48px minimum interactive tap boundaries across all buttons and controls.
- **Performance Optimized:** Fast rendering, zero layout shifts, and responsive image loading.

## Getting Started Locally

### Prerequisites
- Node.js (v18.0.0 or higher)
- Angular CLI (`npm install -g @angular/cli`)

### Installation and Run

```bash
git clone https://github.com/M20A03/Cake-Heaven.git
cd Cake-Heaven
npm install
npm start
```
